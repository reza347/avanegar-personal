# آوانگار ۰.۴ 🇮🇷
برنامهٔ اندرویدی شخصی برای تبدیل **گفتار فارسی به نوشتار زنده** با اعتبار OpenAI API خودتان.

## امکانات
- صفحه تیره و خلوت: یک کادر بزرگ متن و کنترل‌های پایین.
- مشاهده کلمات هنگام حرف‌زدن با مدل gpt-live-transcribe و حالت کمترین تأخیر.
- دکمه مرکزی برای شروع، مکث و ادامه؛ نمایش مدت ضبط با ارقام فارسی.
- دکمه سطل زباله برای پاک‌کردن متن و ضبط ذخیره‌نشده (با تأیید).
- دکمه ✓ برای پایان ضبط و ذخیره متن و صدای WAV در حافظه خصوصی گوشی.
- لمس کادر متن = کپی کامل متن.
- تاریخچه ۵۰ ضبط آخر؛ بازکردن، پخش فایل صوتی، اشتراک متن و حذف.
- اصلاح املای فارسی و نیم‌فاصله‌ها با مدل متنی gpt-6-luna در پس‌زمینه (قابل خاموش‌کردن از تنظیمات).
- تبدیل فایل صوتی به متن با gpt-transcribe، گرفتن خروجی TXT و اشتراک متن.
- ورود کلید OpenAI API فقط از داخل تنظیمات با ذخیره رمزنگاری‌شده در Android Keystore.

## راهنمای استفاده
۱. فایل APK ساخته‌شده توسط GitHub Actions را نصب کنید.
۲. چرخ‌دنده بالا سمت چپ > کلید API > ذخیره.
۳. روی دکمه «شروع ضبط» بزنید و مجوز میکروفون بدهید.
۴. متن در کادر ظاهر می‌شود؛ برای مکث و ادامه دکمه وسط را بزنید.
۵. با تیک ✓ متن و صدای همان ضبط را در تاریخچه ذخیره کنید.
۶. برای کپی همه متن روی کادر بزنید.

## نکات
- برای رونویسی زنده اینترنت لازم است؛ نمایش دلتاها وابسته به شبکه و سرعت مدل است و تأخیر صفر تضمین نمی‌شود.
- ضبط فقط زمانی فعال است که برنامه در پیش‌زمینه باشد؛ بیرون‌رفتن از برنامه ضبط را مکث می‌کند.
- اصلاح املایی درخواست جداگانه به API می‌فرستد و مصرف اعتبار اضافه دارد؛ اگر مدل ویرایش در حسابت در دسترس نباشد متن خام حفظ می‌شود.
- نسخه برای استفاده شخصی با کلید API ذخیره‌شده روی دستگاه ساخته شده است؛ با وجود Keystore، برنامه‌ها و دستگاه‌های آلوده ممکن است خطر ایجاد کنند. کلید را به مخزن GitHub یا افراد دیگر ندهید.
- فایل WAV خصوصی داخل فضای برنامه ذخیره می‌شود و با پاک‌کردن داده‌های برنامه از بین می‌رود.
- هزینه از اعتبار OpenAI API کسر می‌شود و ارتباطی به اشتراک ChatGPT ندارد.
- امکان نصب روی Android 8 به بالا وجود دارد. برای نصب مطمئن، فایل APK باید روی گوشی واقعی آزمایش شود.

## ساخت APK
در مخزن GitHub، تب Actions > Build Android APK، فایل تولیدی از Artifacts قابل دریافت است.

## نسخه ۰.۴.۱: تشخیص نام مکان‌ها
گزارش کاربر: «حاجی‌آباد، بلوار بهشتی» اشتباه شناسایی می‌شد. حالا رونویسی زنده در حالت کم‌تأخیر (`low`) اجرا می‌شود، فهرست نام‌های خاص و خیابان‌ها را به‌عنوان راهنمای واژگانی به مدل ارسال می‌کند و در تنظیمات می‌توان نام‌های پرتکرار را به‌صورت هر خط یک واژه وارد کرد. حالت «دقت بالاتر» تأخیر را از `low` به `medium` تغییر می‌دهد. این راهنماها تشخیص درست نام‌ها را تضمین نمی‌کنند؛ برای بهبود دقت روی گوشی واقعی باید آزمایش شود.
