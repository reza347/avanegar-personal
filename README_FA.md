# آوانگار | Avanegar (v0.3)

برنامه اندروید شخصی تبدیل زندهٔ **گفتار فارسی به متن** با OpenAI.

- صفحه مینیمال: یک کادر بزرگ، یک دکمه ضبط آنلاین، چرخ‌دندهٔ تنظیمات بالا سمت چپ.
- روی متن یک بار بزنید تا **تمام متن** کپی شود.
- در تنظیمات: ذخیرهٔ کلید OpenAI API (با Android Keystore)، تست اتصال، تبدیل فایل صوتی، تاریخچه، خروجی TXT، اشتراک، پاک‌کردن متن.
- زبان رابط فارسی، راهنمای تشخیص گفتار **fa**، جریان WebSocket با **gpt-live-transcribe** و ارسال منظم قطعات صوتی ۳ ثانیه‌ای.
- کلید کاربر را در GitHub یا پیام‌ها قرار ندهید. اتصال مستقیم از اندروید به OpenAI فقط مناسب استفاده شخصی است.

## دانلود APK
از بخش **Actions** همین مخزن، اجرای موفق «Build Android APK» را باز کنید؛ فایل APK از قسمت Artifacts دانلود می‌شود.

## ساخت
Android SDK 35, Kotlin, Gradle 8.11.1. GitHub Actions به شکل خودکار `assembleDebug` اجرا می‌کند.

**توجه:** بدون کلید API و آزمایش روی گوشی واقعی نمی‌توان درست‌بودن تشخیص گفتار را تضمین کرد. قبل از نصب نسخهٔ جدید ممکن است به‌دلیل تفاوت امضای APK لازم باشد نسخهٔ قبلی را حذف کنید.
