# آوانگار (Avanegar)

برنامهٔ اندرویدی شخصی برای تبدیل گفتار فارسی به متن با اعتبار OpenAI API کاربر.

ویژگی‌ها: رابط فارسی، ورود کلید API از تنظیمات، رونویسی زنده و تبدیل فایل صوتی به متن.

⚠️ کلید API را در مخزن GitHub یا چت منتشر نکنید.

در حال آماده‌سازی نسخهٔ اولیه و راه‌اندازی ساخت خودکار APK با GitHub Actions.
