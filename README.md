# آوانگار 🎙 — تبدیل گفتار فارسی به متن

اپلیکیشن اندروید برای استفادهٔ شخصی با اعتبار **OpenAI API** کاربر و رابط کاملاً فارسی و راست‌به‌چپ. این پروژه مستقل است و کپی برند یا کد Soniox نیست.

## امکانات
- 🎙 رونویسی زندهٔ فارسی از میکروفون با WebSocket و مدل `gpt-live-transcribe`
- 🎧 تبدیل فایل صوتی به متن فارسی با مدل `gpt-transcribe` (حداکثر ۲۴ مگابایت)
- ⚙️ واردکردن، آزمایش و حذف کلید OpenAI API از **داخل تنظیمات برنامه**
- 🔐 رمزگذاری کلید روی دستگاه با Android Keystore
- 📝 نمایش و ویرایش متن، ذخیره تاریخچه، کپی، اشتراک‌گذاری و خروجی TXT
- 🎨 رابط تاریک و فارسی؛ گزینه‌ای برای تغییر زبان به غیر فارسی وجود ندارد

## دانلود APK
1. به تب [Actions](https://github.com/reza347/avanegar-personal/actions/workflows/android.yml) بروید.
2. آخرین اجرای موفق **Build Android APK** را باز کنید.
3. در بخش **Artifacts** روی **Avanegar-Persian-APK** بزنید و فایل ZIP را دانلود کنید.
4. ZIP را استخراج کنید و `app-debug.apk` را روی اندروید نصب کنید.

نسخهٔ حاضر **Debug APK** است و با کلید پیش‌فرض توسعه امضا می‌شود؛ برای انتشار عمومی مناسب نیست.

## فعال‌سازی
1. اعتبار OpenAI API باید از اشتراک ChatGPT جداگانه موجود باشد.
2. بعد از نصب برنامه، «تنظیمات کلید OpenAI» را باز کنید و کلید API را در همان گوشی وارد کنید.
3. روی «ذخیره کلید» و سپس «آزمایش اتصال» بزنید. آزمایش فقط اعتبار کلید را بررسی می‌کند، نه لزوماً دسترسی به مدل.
4. برای صدای زنده اجازهٔ میکروفون بدهید یا فایل صوتی انتخاب کنید.

## نکته‌های امنیتی و محدودیت‌ها
**کلید API را هرگز در GitHub، Issues، اسکرین‌شات یا پیام‌ها قرار ندهید.** این برنامه برای مصرف شخصی است؛ استفاده مستقیم از کلید بلندمدت داخل هر برنامهٔ موبایل در گوشی آلوده/روت‌شده کاملاً مصون از استخراج نیست. متن‌های تاریخچه در حافظهٔ خصوصی برنامه ذخیره می‌شوند و رمزگذاری مجزا ندارند.

- اتصال به `api.openai.com` لازم است. هزینه‌ها از اعتبار OpenAI API کم می‌شود؛ محدودیت هزینه را از حساب OpenAI تنظیم کنید.
- راهنمای زبان `fa` به API ارسال می‌شود، اما خروجی ۱۰۰٪ فارسی و دقت هم‌سطح Soniox تضمین نمی‌شود.
- ضبط زنده فقط در پیش‌زمینه اجرا می‌شود؛ تشخیص سکوت سادهٔ محلی برای قطع بخش‌های صوتی به‌کار می‌رود و ممکن است در محیط پرسروصدا دقیق نباشد.
- تا آزمایش روی گوشی واقعی با کلید شخصی، عملکرد در تمام گوشی‌ها و شبکه‌ها تأیید نشده است.

## ساخت
پروژهٔ Native Android با Java 17، Gradle 8.11.1، Android Gradle Plugin 8.7.3 و SDK 35 است. GitHub Actions با هر Push روی main، APK می‌سازد.
